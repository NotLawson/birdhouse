# 🏠 Birdhouse (WIP)
> Check in on who's been eating all your birdseed!

## Intro
Project is my End of Semester project for my headstart course at QUT, specifically for the unit IFB102. In this unit, we worked with Raspiberry Pi 4Bs in order to introduce some basic computing concepts. This project requires us to use a Raspberry Pi 4B to demonstrate a at least two of the technologies taught in the unit.

The basic idea for this project is to capture a short 15 second clip using a camera and microphone, an array of environmental data and send it back to a home server either every 30 minutes or whenever a PIR sensor detects motion next to a tray of birdseed.
